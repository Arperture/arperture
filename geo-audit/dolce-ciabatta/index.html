Technical Readiness

7 / 20

The site is crawlable and AI bots aren't blocked — that's better than many SMBs who accidentally toggle "block AI crawlers" in Cloudflare. Everything else needs work.

✗ Organization / LocalBusiness JSON-LD schema Not found AI can't confirm business identity, category, or location from the site
✗ FAQPage schema Not found No FAQ pages anywhere on the site
✗ Service / additional schema types Not found Zero schema beyond basic HTML microdata on <html> tag
✓ AI crawlers not blocked Open robots.txt only blocks /wp-admin — GPTBot, ClaudeBot, PerplexityBot can crawl freely
✗ llms.txt present Absent No AI-readable site summary (quick win — 30 min to fix)
⚠ Clean heading hierarchy Partial Single H1 present but reads "We Are A Team Of Early Risers" — says nothing about what, where, or for whom
✓ Static HTML content readable without JS Passes Content renders in static HTML — AI crawlers can read what's there
Site architecture red flag: The public website has only 3 navigable pages — Home, Order Online (off-domain), and Contact. All menus are PDF files, completely invisible to AI crawlers. When an AI assistant asks "what pastries does Dolce & Ciabatta sell?" — the website has no answer.
