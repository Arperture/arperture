1 Unblock AI crawlers on SiteGround

CriticalImpact: CriticalEffort: Low

The 403 is coming from the server/CDN, not WordPress. Check these four places in order — the culprit is almost always one of the first two.

1a · Check .htaccess for a user-agent block. Someone may have pasted a "block bad bots" snippet that also catches AI crawlers.

Site Tools → Site → File Manager → public_html/.htaccess

Look for lines like RewriteCond %{HTTP_USER_AGENT} ... ending in [F]/[F,L], or SetEnvIfNoCase User-Agent ... bad_bot + Deny from env=bad_bot, or BrowserMatchNoCase rules. If any list GPTBot / ClaudeBot / PerplexityBot / "bot" broadly, remove those bots from the block (or remove the rule). Save a backup copy first.

1b · SiteGround's own bot blocking. SiteGround can block AI/scraper bots at the account level.

Site Tools → Security → Blocked Bots / Bot Protection  (also check Speed → Caching)

If there's an "AI bots" / "block resource-intensive bots" toggle, disable it for the crawlers you want (GPTBot, ClaudeBot, PerplexityBot, Google-Extended, CCBot).

1c · Cloudflare (if your site uses SiteGround's Cloudflare integration or your own Cloudflare).

Cloudflare dashboard → Security → Bots → turn OFF "Block AI Scrapers and Crawlers"
Cloudflare → Security → Settings → turn OFF "Bot Fight Mode" · check WAF → Custom rules for UA blocks

1d · SiteGround WAF / ModSecurity. If still blocked, open a SiteGround support chat and ask them to "allow GPTBot, ClaudeBot, PerplexityBot, Google-Extended and CCBot through the WAF/ModSecurity — they're returning 403." They can whitelist the rule fast.

How to verify the fix: use a free "user-agent test" / "fetch as GPTBot" tool, or ask me to re-run the audit. A correctly-fixed site returns HTTP 200 to User-Agent: GPTBot on the homepage.

4 Add a visible FAQ section

Impact: HighEffort: Med

Create a /faq/ page (and a short FAQ block on the homepage + services page). Lead every answer with the direct fact — that's what engines extract. Full copy is in faq-content.md. The six starter Q&As:

  • What does Yield Bookkeeping do?
  • Is your bookkeeping done in the US? (lead with "Yes — 100% US-based")
  • Who do you work with?
  • Do you work remotely nationwide?
  • What software do you use?
  • How do I get started?

Keep the visible text in sync with the FAQ JSON-LD from Step 3.
