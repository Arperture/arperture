# Yap script — the proven template

Use this structure every time. Target **~110–160 words** total.

## Structure

1. **HOOK (line 1, ≤ ~15 words).**
   Scroll-stopper. Contrarian claim, curiosity gap, or direct ICP callout.
   No greeting, no preamble. Adapt a pattern from the hook swipe file.

2. **TENSION / REFRAME (2–4 lines).**
   State the common belief, then undercut it. Name the real mechanism or the
   thing nobody's saying. This is where you earn the "here's what nobody's
   telling you" promise.

3. **PAYOFF (2–4 lines).**
   The actual insight or takeaway. Concrete, specific, tied to the ICP's pain.
   If you promised a number ("3 things"), deliver exactly that.

4. **BUTTON (line, ≤ ~15 words).**
   One quotable closing line that recontextualizes the hook. Often a
   "do X, not Y" reframe. This is the line people screenshot or quote.

## Style rules (the script is read verbatim by HeyGen TTS)

- Short, spoken sentences. Read it out loud — if you stumble, rewrite it.
- No stage directions, no emojis, no markdown, no "[pause]". Every character
  is spoken.
- Active voice. Second person ("you") to address the viewer directly.
- One idea only. Cut anything that isn't load-bearing.
- Match the user's brand voice from `assets/brand-context.md`.

## Output

Return ONLY the spoken script as plain prose (no headers, no labels). Keep a
separate note of the hook line and word count for the run log.
