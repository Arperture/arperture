# Hook swipe file

Save viral hooks you find in the wild here. When the skill drafts a script, it
adapts a proven pattern from this list instead of inventing one cold. Add to it
regularly — scroll Reels/TikTok/Shorts, find hooks that stopped *you*, write
them down.

Format: one hook per line. Keep them verbatim; you'll adapt the specifics later.

## Contrarian / pattern-interrupt
- Everyone's using AI to pump out more content. That's exactly why they're invisible.
- If your 2026 strategy is AI doing all the heavy lifting, it won't work.

## Curiosity gap
- Here's what nobody's telling you about [topic].
- Here's the thing no one says out loud about [topic].

## ICP callout
- If you're a [audience] still doing [common thing], stop.

## Stakes / loss
- You're losing [outcome] every day you keep doing [thing].

## Numbered promise
- 3 things I'd never do if I were starting [thing] over.
